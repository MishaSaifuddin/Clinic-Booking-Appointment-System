# Clinic-Booking-Appointment-System
System Analysis &amp; Design Case Study

📌 Project Title

Online Clinic Booking Appointment System – System Analysis & Design Case Study

🧠 Project Overview

This project is a real-world system analysis and design case study developed for Klinik Ceria, a healthcare clinic located in Batu Pahat, Johor. The main goal was to analyze an existing manual appointment process and design a web-based booking appointment system that improves efficiency, reduces miscommunication, and enhances patient experience.

The project was conducted as part of BIC21003: System Analysis and Design, following a structured Software Development Life Cycle (SDLC) approach.

🎯 Problem Statement

Klinik Ceria relied on manual appointment booking via phone calls and social media platforms (e.g., WhatsApp), which caused:

Long waiting times

Missed or overlooked appointments

High administrative workload for clinic staff

Difficulty in booking appointments in advance

This highlighted the need for a centralized, online appointment booking system.

✅ Project Objectives

Analyze the existing appointment booking process at a real clinic

Gather requirements directly from stakeholders (doctor & staff)

Design an online booking system that is user-friendly and efficient

Apply Waterfall SDLC methodology in a structured manner

Produce complete system documentation (DFD, ERD, feasibility study, etc.)

🛠 Methodology & Approach

Software Development Methodology:

Waterfall Model (Planning → Analysis → Design → Implementation → Maintenance)

Requirement Elicitation Techniques:

Stakeholder interview (clinic doctor)

Document analysis

Questionnaire & observation

🧩 System Features (Designed)

Doctor availability based on schedule

Patient information management

Centralized appointment database
